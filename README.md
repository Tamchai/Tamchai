## 🎯 About The Project

> A **pixel-art Pokémon-themed roguelike** game built with Python and Pygame, developed as part of an Object-Oriented Programming & Data Structures course project.

Players choose a starter Pokémon, battle through randomized encounters across multiple areas, collect items, and catch new Pokémon to build their team — all powered by real data structures implemented from scratch.

---

## ✨ Features

- ⚔️ **Turn-based Battle System** — Fight wild Pokémon with move selection
- 🎲 **Random Pokémon Encounters** — Each stage spawns randomized wild Pokémon
- 🎒 **Inventory System** — Collect and use items after winning battles
- 🔴 **Catch Pokémon** — Capture wild Pokémon to add to your team
- 🗺️ **Stage Progression** — Clear stages to advance through different areas (Forest → Cave → Tower → Beach)
- 📈 **Level System** — Pokémon gain levels through battles

---

## 🧠 Data Structures Used

```python
data_structures = {
    "Queue":               "Manages turn order in battle ⚔️",
    "2D Doubly LinkedList":"Powers battle menu & move selection UI ↑↓←→",
    "Tree":                "Represents stage progression map 🗺️",
}
```

| Structure | Usage |
|---|---|
| **Queue** (Linked List-based) | Manages turn order in battle |
| **2D Doubly Linked List** | Powers the battle menu and move selection UI (navigate ↑ ↓ ← →) |
| **Tree** | Represents the stage progression map (Forest → Cave → Tower → Beach → Tower) |

## 🕹️ How to Play

### Controls

| Key | Action |
|:---:|:---:|
| `Arrow Keys` | Navigate menus / Move |
| `Z` | Confirm / Select |
| `X` | Cancel / Go back |
